# Inkdown — 开发任务清单（TASKS）

> 版本：`v1.0-draft` · 当前阶段：**M0 / T006（下一步）；T001 待补手工验收** · 更新日期：2026-11-10
>
> 关联：[`PRD.md`](PRD.md) · [`TECH_SPEC.md`](TECH_SPEC.md) · [`AGENTS.md`](../AGENTS.md)

## 使用说明

- 这是**任务与验收清单**，不是“AI 一次性生成项目”的指令。
- 开发者以亲自编码为主；AI 协助分析、提示 API、Review 和设计测试。
- 每个任务完成前必须实际运行验证，不能因为生成了代码就勾选。
- 优先完成一个小任务，再进行下一项；技术决策变化应同步更新 `TECH_SPEC.md`。
- 参考投入为每日 4 小时以上；预估开发日只是粗略安排，不是交付承诺。

## 阶段计划

| 阶段 | 交付成果 | 参考工作量 | 关口 |
| --- | --- | --- | --- |
| **M0 技术验证** | 能演示即时渲染的小原型 | 4–6 开发日 | 决定是否继续 QTextEdit |
| **M1 个人可用首版** | 新建、打开、直接编辑渲染内容、保存 Markdown | 5–8 开发日 | 安全往返、基础测试 |

| **M5 Windows 适配** | Windows 构建与验证 | 另行评估 | 跨平台验收 |

## M0 — QTextEdit 技术验证（最高优先级）

### T001 — Qt 项目骨架

- [ ] 安装 Qt 6、CMake、编译器、Qt Creator（或等效 IDE）。
- [ ] 创建使用 C++17 的 CMake 项目，配置 Qt Widgets。
- [ ] 创建 `QApplication`、`QMainWindow`、`QTextEdit` 最小窗口。
- [ ] 能 Debug 启动，能输入、复制、粘贴普通文本。

**验收：** macOS 上运行，Debug 构建无报错。**输出：** 第一个可运行提交。

已验证 Debug 构建、调试启动和窗口显示；普通文本输入与复制粘贴待单独确认。

### T002 — 一级和二级标题触发

- [x] 继承 `QTextEdit`，从当前光标获取所在文本块。
- [x] 先在合法行首识别 `# `，局部移除前缀并设一级标题块格式。
- [x] 一级标题验证通过后，再用同样的流程支持 `## `。
- [x] 连续输入保持标题格式；回车进入普通段落。
- [x] 测试光标在首尾、撤销前后的表现。

**验收：** `# ` 和 `## ` 分别转换为一、二级标题，继续输入后按 Enter 回到正文，全程无光标乱跳。

Qt Test 验证了两级标题的段首、段尾和回车行为。仅输入标记并转换后，撤销回到空白正文，重做恢复标题，光标均在段首；后续在 T005 验证继续输入后的撤销顺序。

### T003 — 粗体触发 `**hello**`

- [x] 判断起止标记完整和转义情况。
- [x] 仅操作匹配范围，隐藏 `**` 并应用粗体。
- [x] 支持在中间修改、删除、选中和粘贴。
- [x] 记录可见文本与原始 Markdown 含义的差异。

**验收：** 无字符重复、丢失或选区异常。

原型只处理段尾简单粗体；转义、连续星号和复杂匹配保留原文。转换后可见文本没有 `**`，粗体含义保留在字符格式中；导出和重开由 T006 验证。Qt Test 已验证粗体中插入、退格、选区和纯文本粘贴。

### T004 — 列表触发 `- `

- [x] 在行首识别无序列表触发。
- [x] 使用 Qt 列表/文本块格式实现一层无序列表。
- [x] 回车创建下一项；空列表项回车退出。
- [x] 测试列表前后普通段落。

**验收：** 连续输入、退出列表稳定。

Qt Test 验证了单层圆点列表、回车续项、空项退出、前后正文保留，以及标题或已有列表项中的 `- ` 不触发转换。

### T005 — Undo/Redo 实验

- [x] 测试普通输入、标题、粗体和列表转换撤销。
- [x] 测试格式转换之后再继续输入的多次撤销/重做。
- [x] 尝试 `beginEditBlock()` / `endEditBlock()`，记录事务效果。
- [x] 不符合预期的情况记录成可复现步骤。

**验收：** 无明显内容损坏，清楚记录原生 undo 的能力边界。

Qt Test 验证了普通输入、标题、粗体和两项列表的连续撤销/重做。转换操作分组后，输入 `**hi**!` 再撤销两次会直接恢复 `**hi**`，不再出现只恢复一侧标记的中间状态。列表续项仍可能有一次外观不变的撤销步骤。对 `# - `、`- - ` 继续输入，已确认提前返回不会留下未结束的分组，文档正常发出 `contentsChanged`。

### T006 — Markdown 往返

- [ ] 将原型内容导出成 `.md`。
- [ ] 再次打开并恢复标题、粗体和列表。
- [ ] 对照测试中文、Emoji、空行、不完整语法，以及不支持的语法原文是否保留。
- [ ] 验证 Qt 原生导出存在的语法规范化或信息丢失风险。

**验收：** 基础语义正确，失败案例记录在 `TECH_SPEC.md`。

### T007 — 中文输入法

- [ ] macOS 拼音输入法：候选/组合/提交正常。
- [ ] 测试中文标点、中英文混合、格式文本内输入。
- [ ] 确认未在 preedit 阶段触发破坏性转换。

**验收：** 中文可以连续输入，格式转换不打断候选流程。

### T008 — 核心架构决策

- [ ] 总结光标、选区、IME、undo、源视图同步问题。
- [ ] 明确选用：继续 QTextEdit / 定制布局 / 其他方案。
- [ ] 更新 `TECH_SPEC.md` 的 ADR-006 与风险登记。

**M0 退出条件：** V01–V06 最低通过。标记展开实验留到后续。若阻塞，先修正技术路线，不直接跳 M1。

## M2 — Markdown 编辑核心

### T201 — 行内语法
- [ ] 优先评估行内代码；其余候选为斜体、删除线、链接、转义与嵌套。
- [ ] 处理未闭合标记、歧义情况及代码上下文。

### T202 — 块级语法
- [ ] 三级至六级标题、引用、有序列表、嵌套无序列表、分隔线、围栏代码块。
- [ ] 标题/列表/引用退出规则。

### T203 — 编辑行为
- [ ] 跨块选区、跨格式删除、复制粘贴、光标边界。
- [ ] 处理行内语法区域的编辑和显隐。

### T204 — 源码与视图位置同步
- [ ] 源文本、语义节点、视图位置间的映射。
- [ ] 局部解析、局部视图更新。
- [ ] 保留未知语法源码片段。

### T205 — 撤销事务统一
- [ ] 输入、格式转换、列表操作和模型更新共享一致撤销语义。
- [ ] 多次撤销/重做/保存/重载进行回归。

### T206 — 兼容与数据安全测试
- [ ] 建立 Markdown 语料集和往返测试。
- [ ] 覆盖 Unicode、换行、转义、嵌套、未知语法。
- [ ] 不允许无提示数据丢失。

**M2 退出条件：** 主要 Markdown 结构的编辑和序列化稳定，关键回归测试通过。
